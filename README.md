## 🌟 1. तीन अलग-अलग सिस्टम (Three Separate Systems)

आपकी ज़रूरत के अनुसार पूरे सिस्टम को तीन स्वतंत्र भागों में विभाजित किया गया है, ताकि कोई भी ग्राहक या बाहरी व्यक्ति आपके लीड्स (Customer Leads) न देख सके:

### A. Customer App (ग्राहक ऐप)
* **उद्देश्य**: ग्राहक आसानी से कारपेंटर सेवाएं देख सकें, स्लॉट चुन सकें, पता दर्ज कर सकें और बुकिंग कर सकें।
* **प्रमुख फीचर्स**:
  - सभी 40+ मूल कारपेंटर रेट कार्ड एवं फोटोज़।
  - कैश ऑन सर्विस (Cash on Service) एवं ऑनलाइन UPI (PhonePe, GPay, Paytm) भुगतान।
  - **Start Service OTP**: जब पार्टनर घर पहुंचेगा, तो ग्राहक की स्क्रीन पर 4-डिजिट का Start OTP दिखेगा। बिना इस OTP के पार्टनर काम शुरू नहीं कर सकता।
  - **Completion OTP**: काम पूरा होने के बाद ग्राहक की स्क्रीन पर Completion OTP दिखेगा। ग्राहक की पुष्टि के बाद ही काम पूरा मार्क होगा।
  - वास्तविक रेटिंग एवं रिव्यूज (अधिकतम 3 वास्तविक समीक्षाएं)।
  - कंप्लेंट / सपोर्ट टिकट दर्ज करने की सुविधा।

### B. Partner App (कारीगर / पार्टनर ऐप)
* **उद्देश्य**: केवल अधिकृत पार्टनर अपने असाइन किए गए काम देख सकें।
* **सुरक्षा (Privacy Protection)**: पार्टनर सिर्फ अपने नाम पर असाइन किए गए ऑर्डर देख सकता है। दूसरे पार्टनर्स के ऑर्डर्स या अनअसाइंड लीड्स पूरी तरह छिपे रहते हैं।
* **वर्कफ्लो**:
  1. नया काम स्वीकार (Accept) या अस्वीकार (Reject) करें।
  2. "On The Way" और "Arrived" स्थिति अपडेट करें।
  3. ग्राहक के घर पहुंचकर ग्राहक से **Start OTP** लेकर ऐप में डालें और "Start Work" करें।
  4. काम पूरा होने पर ग्राहक से **Completion OTP** लेकर "Complete Work" करें।
  5. अगर कैश पेमेंट है, तो "Cash Received" बटन दबाकर भुगतान पुष्टि करें।
  6. ग्राहक के पते के लिए डायरेक्ट गूगल मैप्स नेविगेशन।

### C. Admin Panel (मालिक / एडमिन वेब डैशबोर्ड)
* **सुरक्षा**: गुप्त 4-डिजिट Owner PIN (`9993`) द्वारा सुरक्षित।
* **कंट्रोल**:
  - सभी नई बुकिंग्स देखना और पार्टनर को असाइन करना।
  - पार्टनर्स को जोड़ना, एक्टिवेट / डिएक्टिवेट करना।
  - सेवाओं के दाम (Prices) और रेट कार्ड मैनेज करना।
  - ऑनलाइन पेमेंट और कैश कलेक्शन का पूरा हिसाब (Ledger)।
  - ग्राहकों की शिकायतों का निवारण।
  - **बिजनेस कॉन्टैक्ट नंबर बदलना**: आप एडमिन पैनल से सीधे अपना हेल्पलाइन व व्हाट्सएप नंबर बदल सकते हैं, जो ग्राहक ऐप के कॉल बटन में तुरंत अपडेट हो जाएगा।

## 🔨 3. Flutter से Android APK कैसे बनाएं (How to Build APK)

यदि आप कंप्यूटर पर Flutter SDK से सीधे APK फाइल जनरेट करना चाहते हैं:

### स्टेप्स:
1. टर्मिनल खोलें और `Ghar_Seva_Full_Flutter_Starter` फोल्डर में जाएं:
   ```bash
   cd Ghar_Seva_Full_Flutter_Starter
   ```
2. जरूरी पैकेजेस इंस्टॉल करें:
   ```bash
   flutter pub get
   ```
3. रिलीज Android APK बनाएं:
   ```bash
   flutter build apk --release
   ```
4. आपकी APK फाइल तैयार होकर इस पाथ पर मिलेगी:
   ```
   build/app/outputs/flutter-apk/app-release.apk
   ```
5. इस APK को आप अपने किसी भी एंड्रॉयड फोन में ट्रांसफर करके सीधे इंस्टॉल कर सकते हैं!
